# 相平衡计算功能使用指南

## 功能概述

相平衡计算模块基于**吉布斯自由能最小化原理**，实现了多相平衡的精确计算。该模块可以：

1. **计算给定合金组成在一定温度下的平衡相及其占比**
2. **分析相平衡随温度的变化**
3. **分析相平衡随组分含量的变化**

---

## 理论基础

### 平衡条件

系统处于热力学平衡时，吉布斯自由能达到最小值：

```
∂G/∂ξ = 0
```

对于多相系统，平衡条件要求：
- **化学势平衡**: μᵢᵅ = μᵢᵝ (各相中同一组分的化学势相等)
- **物质守恒**: Σ(xᵢᵅ × fᵅ) = xᵢ_total

### 相能量计算

单相的摩尔吉布斯自由能计算公式：

```
G = Σ(xᵢ × μᵢ)

其中化学势:
μᵢ = G⁰ᵢ + RT ln(xᵢ) + RT ln(γᵢ)
```

- `G⁰ᵢ`: 纯组分i在该相的标准吉布斯能量 (来自SGTE数据库)
- `xᵢ`: 组分i的摩尔分数
- `γᵢ`: 活度系数 (通过UEM/GSM等模型计算)

### 支持的相类型

- **LIQUID**: 液相
- **BCC_A2**: 体心立方固溶体
- **FCC_A1**: 面心立方固溶体
- **HCP_A3**: 密排六方固溶体

## 使用方法

### 功能1: 单点平衡相计算

**适用场景**: 已知合金组成和温度,计算平衡时有哪些相以及各相的占比。

#### 操作步骤:

1. 打开"相平衡计算"标签页
2. 选择"平衡相计算"子标签
3. 输入参数:
   - **合金成分**: 例如 `Fe0.70C0.03Si0.27`
   - **温度 (K)**: 例如 `1873`
   - **外推模型**: 选择 `UEM1` / `UEM2` / `GSM` 等
   - **活度模型**: 选择 `Wagner` / `Darken` / `Elliott`
   - **最大相数**: `1` 或 `2`

4. 点击"计算"按钮

#### 输出结果:

- **文本摘要**: 显示平衡状态、温度、总吉布斯能量
- **详细表格**:
  - 相名称
  - 相分数 (%)
  - 吉布斯能量 (J/mol)
  - 各元素的摩尔分数和质量分数
- **饼图**: 可视化各相的占比

#### 示例:

```
输入:
  合金成分: Fe0.97C0.03
  温度: 1800 K
  外推模型: UEM1
  活度模型: Wagner

输出:
  平衡相数: 2
  相1: LIQUID (75.3%)
    组成: {Fe: 0.975, C: 0.025}
    吉布斯能: -52300 J/mol

  相2: FCC_A1 (24.7%)
    组成: {Fe: 0.950, C: 0.050}
    吉布斯能: -50100 J/mol
```

---

### 功能2: 相平衡随温度变化分析

**适用场景**: 固定合金组成,研究从低温到高温过程中相的转变规律。

#### 操作步骤:

1. 选择"温度变化分析"子标签
2. 输入参数:
   - **合金成分**: 例如 `Fe0.70C0.03Si0.27`
   - **起始温度 (K)**: 例如 `1273`
   - **终止温度 (K)**: 例如 `2273`
   - **温度点数**: 例如 `50` (点数越多曲线越平滑)
   - **外推模型**: 选择 `UEM1` 等
   - **活度模型**: 选择 `Wagner` 等

3. 点击"计算"按钮 (会显示进度条)

#### 输出结果:

- **堆叠区域图**:
  - X轴: 温度 (K)
  - Y轴: 相分数 (0-1)
  - 不同颜色区域代表不同的相

- **计算摘要**: 温度范围、发现的相类型

#### 应用示例:

**确定相变温度**: 例如观察Fe-C合金从低温的BCC_A2相到高温LIQUID相的转变点。

---

### 功能3: 相平衡随组分变化分析

**适用场景**: 固定温度和基础合金,研究添加某元素对相平衡的影响。

#### 操作步骤:

1. 选择"组分变化分析"子标签
2. 输入参数:
   - **基础合金**: 例如 `Fe0.97Si0.03` (不含变化元素)
   - **变化元素**: 例如 `C`
   - **最小摩尔分数**: 例如 `0.0`
   - **最大摩尔分数**: 例如 `0.10`
   - **温度 (K)**: 例如 `1873`
   - **组分点数**: 例如 `50`
   - **外推模型**: 选择 `UEM1` 等
   - **活度模型**: 选择 `Wagner` 等

3. 点击"计算"按钮

#### 输出结果:

- **堆叠区域图**:
  - X轴: 变化元素的摩尔分数
  - Y轴: 相分数 (0-1)
  - 显示不同碳含量下各相的占比

- **计算摘要**: 变化元素、温度、发现的相

#### 应用示例:

**研究碳含量对Fe-C-Si合金相平衡的影响**:
- 基础合金: Fe0.97Si0.03
- 变化元素: C
- 范围: 0 ~ 0.10
- 温度: 1873 K

可以观察到:
- 低碳区域: 主要为LIQUID相
- 高碳区域: 可能出现LIQUID + FCC_A1两相区

## 技术细节

### 算法流程

1. **单相能量计算**:
   - 对每个候选相 (LIQUID, BCC, FCC, HCP) 计算总吉布斯能量
   - 选择能量最低的相作为初步结果

2. **两相平衡求解** (对于二元系统):
   - 设置未知量: [x_B_α, x_B_β] (两相中B元素的摩尔分数)
   - 构建方程组:
     - μ_A(α) = μ_A(β)
     - μ_B(α) = μ_B(β)
   - 使用 `scipy.optimize.root` 求解
   - 通过杠杆定律计算相分数:
     - f_α = (x_B_total - x_B_β) / (x_B_α - x_B_β)
     - f_β = 1 - f_α

3. **多元系统简化处理**:
   - 遍历所有可能的两相组合
   - 选择总能量最低的组合

### 数值稳定性优化

- **边界保护**: 摩尔分数限制在 [1e-12, 0.999] 范围内
- **多初值尝试**: 使用不同初值多次求解,选择最佳结果
- **收敛判据**: 残差 < 1e-3

### 性能优化

- **并行计算**: 温度/组分扫描时可添加进度回调
- **缓存机制**: 避免重复计算纯组分能量

---

## 注意事项

1. **计算时间**:
   - 单点计算: < 1秒
   - 温度/组分扫描 (50点): 约10-30秒

2. **精度限制**:
   - 多元系统 (>2组分) 的两相平衡为简化算法
   - 不支持三相或更多相的精确求解

3. **数据依赖**:
   - 需要TDB数据库包含所有元素的热力学数据
   - 活度系数计算依赖于相互作用参数

4. **物理约束**:
   - 相分数之和必须为1
   - 质量守恒和化学势平衡必须同时满足

## 常见问题 (FAQ)

**Q1: 为什么计算结果显示"metastable"?**

A: 这表示虽然找到了单相平衡,但可能存在能量相近的其他相,建议增大"最大相数"或检查温度范围。

---

**Q2: 如何判断计算结果是否合理?**

A: 检查以下几点:
- 相分数之和 = 100%
- 各相组成满足质量守恒
- 吉布斯能量为负值 (相对于标准态)
- 与实验相图或文献数据对比

---

**Q3: 多元系统计算不准确怎么办?**

A:
- 当前版本对多元系统 (>2组分) 使用简化算法
- 建议:
  1. 先用二元子系统验证
  2. 参考实验相图数据
  3. 使用更精确的商业软件 (如Thermo-Calc) 进行对比

---

**Q4: 支持哪些外推模型?**

A:
- **UEM1**: 统一作用能模型 (推荐)
- **UEM2**: 改进的UEM模型
- **GSM**: 几何模型
- **Muggianu**: Muggianu对称模型
- **Toop**: Kohler/Muggianu组合模型

不同模型适用于不同合金体系,建议对比选择。
