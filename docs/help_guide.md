## 1. 软件概述

### 1.1 简介

AlloyThermolCal Pro 是一款基于 UEM-Miedema 模型框架的合金热力学计算桌面应用程序。软件提供活度计算、相图绘制、析出温度预测、溶解度积计算以及 AI 辅助对话等功能，适用于冶金热力学研究和合金设计。

### 1.2 主要功能

| 功能模块 | 说明 |
|---------|------|
| 活度计算 | 计算合金组元的活度、活度系数，支持 Wagner/Darken/Elliott 模型 |
| 相互作用系数 | 一阶系数 ε、二阶系数 ρ、贡献系数、无限稀释活度系数 |
| 热力学性质 | 混合焓、Gibbs 自由能、化学势、熵 |
| 相图计算 | 二元系液相线/固相线温度计算与绘制 |
| 溶解度计算 | 溶质在合金中的溶解度 |
| 析出温度 | 基于热力学平衡条件预测析出温度 |
| 溶解度积 | 碳化物、氮化物等化合物的溶解度积计算和析出分析 |
| 相平衡 | 多相平衡计算（温度扫描、组分扫描） |
| AI 对话助手 | 自然语言交互进行热力学计算 |

### 1.3 理论基础

#### Miedema 模型

Miedema 模型是一种半经验方法，基于元素的电负性（φ*）和电子密度（nws）两个参数预测合金的混合焓。其核心公式为：

$$\Delta H^{mix} = f(c) \cdot [-P(Δφ^*)^2 + Q(Δn_{ws}^{1/3})^2 - R]$$

其中 f(c) 为成分函数，P、Q、R 为经验系数。

#### UEM 外推模型

UEM（Unified Extrapolation Method，统一外推方法）用于从二元子体系的热力学数据外推多元体系性质。主要模型包括：

- **UEM1**（默认）：基于贡献系数的加权外推
- **UEM2**：改进的外推方法
- **Muggianu**：对称几何外推
- **Toop_Muggianu / Toop_Kohler**：非对称外推

#### 活度模型

- **Wagner 模型**（一阶，默认）：ln(γ_i) = ln(γ°_i) + Σ ε_i^j × x_j
- **Darken 模型**（二阶）：在 Wagner 基础上加入二阶修正项 ρ
- **Elliott 模型**（二阶交叉）：使用交叉相互作用系数

## 4. 热力学计算模块

### 4.1 活度计算

计算合金中指定组元的活度 a = γ × x。

**输入参数：**
- 合金成分（摩尔分数，总和自动归一化到 1.0）
- 目标组元
- 温度 (K)
- 相态（liquid / solid）
- 外推模型（UEM1 / UEM2 / Muggianu 等）
- 活度模型（Wagner / Darken / Elliott）

**输出：**
- 活度 a
- 活度系数 γ
- ln(γ)

**操作步骤：**
1. 在成分输入区输入各元素的摩尔分数
2. 选择温度、相态、模型
3. 点击"计算"按钮
4. 结果显示在右侧

### 4.2 活度随温度变化

绘制指定合金组元的活度随温度变化曲线。

**输入：**
- 合金成分
- 目标组元
- 温度范围和步长

### 4.3 活度随浓度变化

绘制活度随某一组元浓度变化的曲线。

### 4.4 活度相互作用系数

#### 一阶系数 ε_i^j

描述溶剂中溶质 j 对溶质 i 活度系数的影响。Wagner 模型中的核心参数。

**输入：**
- 溶剂元素
- 溶质 i、溶质 j
- 温度 (K)

**物理意义：**
- ε > 0：溶质 j 使溶质 i 的活度系数增大（排斥作用）
- ε < 0：溶质 j 使溶质 i 的活度系数减小（吸引作用）

#### 二阶系数 ρ

用于 Darken/Elliott 模型中的高阶活度修正。支持三种类型：
- ρ_i^ii（自相互作用）
- ρ_i^jj（混合相互作用）
- ρ_i^ij（交叉相互作用）

#### 贡献系数

从二元子体系外推到多元体系时的权重因子，共 6 个参数。不同外推模型给出不同的贡献系数值。

#### 无限稀释活度系数 ln(γ°)

溶质浓度趋于 0 时的活度系数对数，基于 Miedema 模型计算化学相互作用能。

### 4.5 热力学性质

| 性质 | 公式 | 说明 |
|------|------|------|
| 混合焓 H | Miedema 模型 | 合金形成时的热效应 |
| Gibbs 自由能 G | G = H - TS | 反应自发性判据 |
| 化学势 μ_i | μ_i = μ°_i(T) + RT·ln(a_i) | 组元的偏摩尔 Gibbs 能 |
| 熵 S | S = (H - G) / T | 混合无序度 |

**输出：**
- 液相线温度 (K, °C)
- 熔点降低值 (K)
- 每百分比降低值 (K/%)

## 7. 析出温度计算模块

### 7.1 热力学法

基于化学势平衡条件 μ_solute(solution) = G°_precipitate 求解析出温度。

**输入：**
- 合金成分（摩尔分数）
- 溶质元素
- 相态（LIQUID / SOLID）
- 温度搜索范围

**输出：**
- 析出温度 (K, °C)
- 驱动力
- 活度系数

### 7.2 Turkdogan 经验法

基于溶解度积经验公式计算析出温度，详见第 9 章。

### 7.3 多溶质析出

计算多种溶质的析出温度，按温度从高到低排列。

## 8. 相平衡计算模块

### 8.1 多相平衡

基于 Gibbs 自由能最小化原理计算多相平衡。

**支持的相：**
- LIQUID（液相）
- BCC_A2（体心立方，α-Fe）
- FCC_A1（面心立方，γ-Fe）
- HCP_A3（密排六方）

### 8.2 计算模式

1. **单点计算**：给定温度和成分，计算平衡相组成
2. **温度扫描**：固定成分，计算不同温度下的相分布
3. **组分扫描**：固定温度，计算不同成分下的相分布

## 9. 溶解度积计算

### 9.1 基本概念

溶解度积（Solubility Product, Ksp）描述化合物在溶液中的溶解平衡。

对于反应 MmXn(s) ⇌ m·[M] + n·[X]，溶解度积定义为：

$$K_{sp} = [\\%M]^m \cdot [\\%X]^n$$

其中 [%M] 和 [%X] 为元素的质量百分数。

### 9.2 经验公式法（Turkdogan）

溶解度积的温度依赖性通常表示为：

$$\log K_{sp} = A - B/T$$

其中 A、B 为经验常数，T 为温度 (K)。

**析出温度计算：**

$$T_{precip} = B / (A - \log[\\%M][\\%X]^n)$$

### 9.3 热力学法

基于 Gibbs 能计算溶解度积：

$$\Delta G°_{diss} = m \cdot G°_M + n \cdot G°_X - G°_{MmXn} = -RT \cdot \ln(K_{sp})$$

### 9.5 AI 助手使用示例

通过 AI 对话助手，可以用自然语言进行溶解度积相关计算：

**计算溶解度积：**
```
用户：计算TiN在1200°C奥氏体中的溶解度积
AI：TiN 在 1473K (1200°C) AUSTENITE 中的溶解度积:
    log(Ksp) = -5.76
    表达式: log[%TI][%N]^1.0 = 4.35 - 14890/T
```

**计算析出温度：**
```
用户：钢中含0.02%Ti和0.005%N，计算TiN在奥氏体中的析出温度
AI：TiN 的析出温度: 1398.2 K (1125.1°C)
    [TI] = 0.02 wt%, [N] = 0.005 wt%
```

**计算平衡溶解度：**
```
用户：1200°C下含0.02%Ti的钢中，平衡氮含量是多少？
AI：在 1473K (1200°C) 下，[TI] = 0.02 wt% 时，
    TiN 中 [N] 的平衡含量 = 0.000087 wt% (0.87 ppm)
```

**计算析出顺序：**
```
用户：含0.015%Ti, 0.025%Nb, 0.08%C, 0.008%N的钢的析出顺序
AI：析出顺序（从高温到低温）:
    | 序号 | 化合物 | 析出温度 (K) | 析出温度 (°C) |
    | 1 | TiN | 1485.3 | 1212.2 |
    | 2 | NbC | 1198.5 | 925.4 |
    | 3 | TiC | 1087.2 | 814.1 |
```

### 9.6 Wagner 活度修正

在多元体系中，溶质之间的相互作用会影响溶解度积。修正后的有效含量为：

$$\log f_M = \sum_j e_M^j \cdot [\\%j]$$

其中 e_M^j 为 Wagner 一阶活度相互作用系数。数据库内置了 1873K 液态铁中 C、N、Ti、Nb、V、Al、S 等元素的相互作用系数。

## 12. 常见问题

### Q1: 成分输入需要注意什么？

- 成分值为**摩尔分数**，总和应为 1.0（软件会自动归一化）
- 百分比需除以 100：如 5% 输入 0.05
- AI 助手会自动解析百分比格式

### Q2: 如何选择活度模型？

| 场景 | 推荐模型 |
|------|---------|
| 稀溶液（溶质 < 5%） | Wagner（一阶，最快） |
| 高浓度合金 | Elliott（二阶交叉，最准） |
| 需要对比 | 三种模型各算一次 |

### Q3: 如何选择外推模型？

- **UEM1**（默认）：多数情况下推荐
- **Muggianu**：对称体系
- **Toop**：非对称体系（一个组元与其他组元性质差异大时）

### Q4: 温度范围有什么限制？

- 液相线计算：300-3000 K
- 溶解度积经验公式：各化合物有不同的适用范围（见第 9 章表格）
- 超出范围的计算结果仅供参考

### Q5: 计算结果不合理怎么办？

1. 检查成分输入是否正确（摩尔分数 vs 质量百分数）
2. 检查温度单位（K vs °C）
3. 尝试不同的外推/活度模型
4. 检查元素数据是否在数据库中

### Q6: 如何使用 Ollama 本地模型？

1. 安装 Ollama: https://ollama.ai
2. 拉取模型: `ollama pull qwen2.5:14b`
3. 在软件中选择 Ollama 后端
4. 地址填写 `http://localhost:11434`
5. 选择已安装的模型

### Q7: AI 助手不调用工具怎么办？

- 确保使用支持工具调用的模型（如 qwen2.5, llama3.1, gpt-4 等）
- 用明确的关键词：如"计算"、"求"、"多少"
- 提供完整的参数信息
